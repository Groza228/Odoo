# Бібліотека

## Структура та звʼязки

Модуль використовує окремі записи `library.member`, а не `_inherits` від
`res.partner`. Читацький квиток не залежить від модуля контактів, тому єдина
залежність модуля — `base`. Для читачів передбачено обовʼязковий унікальний
`membership_number`.

`library.book` — бібліографічний запис із полем `copy_ids` One2many для
фізичних примірників `library.copy`. Кожен примірник має обовʼязкове поле
`book_id` Many2one з `ondelete='restrict'`: видалення книги не повинно
мовчки видаляти її фізичні примірники. Видача має обовʼязкові поля `copy_id`
і `member_id` Many2one, також із `ondelete='restrict'`, щоб зберігати історію
видач, коли примірник або читач уже використовувався.

У формі видачі відображаються повʼязані дані книги та читача. Примірник
вважається вільним, якщо для нього не існує видачі зі станом `active`.

## Згенеровано AI та виправлено вручну

Початкові модель книги, її представлення, меню та мінімальна залежність
`base` були згенеровані без структурних змін. Під час ревʼю вручну додано
моделі примірника, читача та видачі, правила доступу, представлення й демо-
дані.

Поведінку видалення звʼязків обрано вручну: усі обовʼязкові Many2one-поля
використовують `ondelete='restrict'`, а не небезпечний каскад, щоб зберегти
фізичні примірники та історію видач. Також вручну перевірено обовʼязковість
полів книги, примірника, видачі й читача. Обмеження унікальності читачів
реалізовано через API `models.Constraint` в Odoo 19.

## Практика ORM shell

Запуск shell із кореня репозиторію:

```powershell
python odoo-bin shell -c odoo.conf -d Test
```

Наведені запити виконано в базі `Test` 26.10.2026.

```python
env['library.book'].search([('author', '=', 'Роберт К. Мартін')])
```

Результат: `['Чистий код']`.

```python
book = env['library.book'].search([('author', '=', 'Роберт К. Мартін')], limit=1)
free = book.copy_ids.filtered(
    lambda copy: not env['library.loan'].search_count([
        ('copy_id', '=', copy.id),
        ('state', '=', 'active'),
    ])
)
len(free)
```

Результат: `1` вільний примірник книги «Чистий код».

```python
env['library.loan'].search([
    ('state', '=', 'active'),
    ('due_date', '<', fields.Date.today()),
])
```

Результат: одна прострочена активна видача — видача книги «Чистий код»
читачці Анні Коваленко.

```python
loan = env['library.loan'].create({
    'copy_id': env['library.copy'].search([], limit=1).id,
    'member_id': env['library.member'].search([], limit=1).id,
    'due_date': fields.Date.today(),
})
loan.write({'state': 'returned', 'return_date': fields.Date.today()})
```

Результат: нову видачу створено зі станом `active`, а потім змінено на
`returned` із поточною датою повернення.
